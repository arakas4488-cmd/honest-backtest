FAQ

Questions worth asking before you pay anyone for this

Do I need to give you exchange or broker access?

No. I review code and whatever data/results you send me — never live API keys, trading permissions, or custody of funds. There is nothing to hand over access to.

What if you don't find any bugs?

You still get the fee-honest backtest recalculation and the full written report. The audit isn't graded on how many findings there are — a clean result is a real result too.

Is this investment advice?

No. It's a technical read on what your code and your numbers actually show — not a recommendation to trade, and not a guarantee of future performance.

How is this different from just re-running my backtest?

Most of the bugs that matter live in code paths a backtest never exercises — order time-in-force, stop/target computed from the wrong price, silent data-path failures. I read the code first, then recalculate the numbers with realistic fees on top.

How long does it take?

Written report within a week of receiving your code and data, with one round of follow-up questions included at no extra charge.

Do you also fix the bugs you find?

Think of it like a car: a trading bot is a complex machine — it needs periodic diagnostics before you trust it with real money, and sometimes emergency help when something's already gone wrong live. I run that diagnostic honestly whether it takes five minutes or five hours, whether I find one issue or ten — the audit fee never changes based on what I find. If something is actually wrong, fixing it is a separate job, quoted only after you've seen the findings — entirely your call whether to book it here or take the report elsewhere.
